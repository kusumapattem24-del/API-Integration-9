# Lesson 9 Assessment
## Testing, Debugging, and Optimizing API Integrations

## 1. Assessment Overview

This assessment evaluates your ability to test, debug, optimize, and document an n8n API integration workflow by applying the concepts covered in Topic 9. You will configure Postman environments, create JavaScript assertions, analyze n8n execution history, troubleshoot workflow failures, implement parallel execution using the Merge node, and validate workflow performance. The assessment is based on the provided Requirement Document and Implementation Guide.

## 2. Assessment Objective

Demonstrate your ability to build, test, debug, and optimize API integrations using Postman and n8n while following industry best practices for validation, troubleshooting, workflow optimization, and documentation.

## 3. Prerequisites

- Review the Requirement Document before starting the assessment.
- Review the Implementation Guide for the complete workflow.
- Complete Topics 1–8.
- Install and configure n8n and Postman Desktop.
- Have internet connectivity for API testing and a GitHub account for source code submission (if applicable).

## 4. Assessment Tasks

### Exercise 1 – Configure Postman Environment
Create a Postman environment with base_url and user_id variables and verify dynamic requests.

### Exercise 2 – Implement JavaScript Assertions
Write Postman test scripts to validate HTTP status, response time, and returned JSON data.

### Exercise 3 – Debug Workflow Execution
Inspect n8n Execution History, analyze node inputs/outputs, identify errors, and troubleshoot failures.

### Exercise 4 – Optimize Workflow Performance
Build parallel HTTP Request branches with a Merge node and compare sequential versus parallel execution.

### Exercise 5 – Validate and Submit Deliverables
Verify workflow execution, document observations, and prepare all required deliverables.
